# Honey Badger Haze Pheno Hunt - Legacy Dashboard

Archived static HTML dashboard for the **Honey Badger Haze** pheno hunt
((C99 x White Widow) x Ms. Universe #10, Dynasty Genetics lineage).

Split out of `joeydouglas/honey-badger-haze-pheno-hunt`, which is now the
pure **data repo** (`project.md` + `plants/<ID>.md`) that `breeding-data-api`
clones and serves.

This repo holds only the generated static output (`index.html`, `style.css`,
`plants/*.html`) produced by `generate_dashboard.py`. It is retained for
historical reference during the Phase 3-7 frontend cutover.
